# Finora

Finora is a personal finance app for tracking income, expenses, budgets, and savings
goals by hand — no bank connection required. This Storybook is its design system: the
building blocks the app's screens are assembled from, in isolation, in both light and
dark mode.

## Typography

Finora pairs a serif display face for headings with a plain sans-serif for everything
else that needs to read quickly — amounts, labels, body copy.

## Colors

Every color below is a CSS custom property (`--color-finora-*` in `styles/theme.css`),
each with its own dark-mode value — components should always reference the token, never
a hardcoded color, so they render correctly in both themes automatically.

## How this is organized

Components are grouped by how small and reusable they are: simple, single-purpose
pieces first, then compositions of those pieces into more complete UI. Every component
has its own colocated tests (`*.test.tsx`) alongside its story.
